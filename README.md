# GNS Kids

Shows, games, music and fun for kids from GNS.

Live site: https://glennbourbon7-web.github.io/gns-kids/

## Powers Points

Win games to earn Powers Points from Richard Powers, then spend them in the **My Avatar** closet to unlock clothes (tops, bottoms, shoes, hats and extras). New players start with 25 points.

| Game | Points |
| --- | --- |
| From Hovel to the House | Finish the story: 50 |
| GNS Fact Desk | 6+ right: 20 · 8+: 40 · 10/10: 60 |
| Beaver Trapping | 15+ pts: 15 · 30+: 30 · 45+: 50 |
| Big Ole' Red Cookie | 1 star: 15 · 2 stars: 30 · 3 stars: 50 |
| GNS Word Search | Find all 10 words: 40 |
| GNS Crossword | Solve it without "Show answers": 60 |

Points and clothes are saved in the player's browser. The site asks the browser to keep that save permanently, and the **Keep your points and avatar** box under My Avatar gives each player a save code to move their points and avatar to the GNS Kids app or another device. The code lives in `powers-points.js`.
